# Social kit

Generated by `scripts/build-social-kit.mjs`. Regenerate after a brand
change:

```bash
npm run brand:social-kit
```

## Avatars

Every platform masks the avatar to a circle, so the mark sits well inside
the inscribed circle — nothing important reaches the corners.

| File | Where |
|---|---|
| `avatar-400.png` | Mastodon, Bluesky, most fediverse software |
| `avatar-512.png` | X, Telegram |
| `avatar-1000.png` | LinkedIn (page and personal), GitHub organisation |
| `avatar-light-400.png` | anywhere the surrounding UI is dark and the ink version disappears |

## Banners

Each network crops a different strip, and mobile crops harder than
desktop. The wordmark is centred because the centre is the only region
every platform keeps.

| File | Where |
|---|---|
| `banner-x-1500x500.png` | X header |
| `banner-mastodon-1500x500.png` | Mastodon header (same size; kept separate so the two can diverge) |
| `banner-bluesky-3000x1000.png` | Bluesky banner |
| `banner-linkedin-page-1128x191.png` | LinkedIn **company page** cover |
| `banner-linkedin-profile-1584x396.png` | LinkedIn **personal profile** cover |
| `banner-github-1280x640.png` | GitHub organisation profile |

LinkedIn's two covers are different shapes — using the profile one on a
page crops the wordmark in half.
